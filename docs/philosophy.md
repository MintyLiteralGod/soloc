# Why SoloC exists

SoloC is SoloGem's answer to a simple question:

> What if a real programming language felt as gentle as a first tutorial?

## The goal

Make SoloC **the easiest language to learn** — without pretending programming is magic, and without hiding how computers work.

Beginners should feel progress in minutes: print something, store a value, make a decision, write a function.

## Designed for humans first

SoloC borrows familiar shapes from **C#** so skills transfer later — then removes friction:

| Idea | How SoloC keeps it easy |
|------|-------------------------|
| Run something | Top-level scripts — no class required |
| Name a value | `var` and `let` with clear rules |
| Reuse logic | Short `fn` functions |
| Grow up | Classes, arrays, and modules when you're ready |
| Mistakes | Friendly errors with `line:column` |

## One small step at a time

The [learn path](learn/00-welcome.md) teaches one idea per lesson. Each page has tiny examples you can type and run. No wall of theory before you see output.

## Honest power, clear edges

SoloC is open source under the **MIT** license. Under the hood you'll find type checking and a bytecode VM — tools that make programs safer and faster. You can ignore them while you learn, then peek at [vm.md](vm.md) when you're curious.

## Brand promise

If SoloGem builds it, the first experience should feel:

- **Warm** — encouraging tone in docs and errors
- **Clear** — short words, short samples
- **Finishable** — a path from hello to a small project
