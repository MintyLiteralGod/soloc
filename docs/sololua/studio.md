# SoloLua Studio

Browser GUI for SoloLua — SoloGem Solo5.

```bash
dotnet run --project src/SoloLua.Studio
```

Open **http://localhost:5092**

- Live compile to Lua
- Demo gallery (lists, class, operators, try/catch)
- Download `.lua`
- Notes panel — what SoloLua changes vs stock Lua
