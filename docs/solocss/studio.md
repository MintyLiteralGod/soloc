# SoloCSS Studio

Dedicated browser GUI for SoloCSS — SoloGem Solo5.

## Run

```bash
dotnet run --project src/SoloCss.Studio
```

Open **http://localhost:5090**

## What’s inside

- Live editor → CSS preview (sample page uses your stylesheet)
- Demo gallery (theme, cards, nav)
- Download compiled `.css`

## CLI

```bash
dotnet run --project src/SoloCss.Cli -- compile examples/css/showcase.solocss
```
