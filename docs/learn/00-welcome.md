# 00 — Welcome to SoloC

Hi. You're about to learn **SoloC**, an open-source programming language made by **SoloGem**.

The goal is simple: make SoloC the **easiest language to learn**. Short lessons. Tiny examples. Friendly errors.

## What is SoloC?

- Inspired by **C#**, but simpler
- Programs live in `.sc` files
- You can write a full program in one line
- MIT open source — free to use and share

## What you'll need

- The [.NET 8 SDK](https://dotnet.microsoft.com/download)
- This repository (clone or download)
- Curiosity — that's enough

## How these lessons work

Each lesson teaches **one idea**. Read a little, type a little, run it, smile.

| Lesson | Topic |
|--------|--------|
| 01 | Print text |
| 02 | Variables |
| 03 | Decisions (`if`) |
| 04 | Loops |
| 05 | Functions |
| 06 | Arrays |
| 07 | Classes |
| 08 | Projects & next steps |

## Your first peek

```soloc
print("Welcome to SoloC!");
```

That's a complete program.
