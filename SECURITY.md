# Security Policy

SoloGem takes security seriously — even for a learning language.

## Supported versions

Please report issues against the latest code on the default branch.

## How to report a vulnerability

**Do not** open a public GitHub issue for security problems.

Instead, email **security@sologem.dev** (or **community@sologem.dev** if that address is unavailable) with:

- A short description of the issue
- Steps to reproduce
- What you expected vs. what happened
- Impact (e.g. crash only, unexpected code execution, path issues)

You should get an acknowledgment within a few days. SoloGem will work with you on a fix and credit (if you want it) when the issue is resolved.

## Scope

In scope:

- The SoloC compiler, CLI, and runtime (`src/`)
- Official examples and tooling that ship with this repo

Out of scope:

- Hypothetical issues in third-party forks
- Social engineering or physical attacks

Thank you for helping keep SoloC safe for learners.
