# SoloJS Studio

Dedicated browser GUI for SoloJS — SoloGem Solo5.

## Run

```bash
dotnet run --project src/SoloJs.Studio
```

Open **http://localhost:5091**

## What’s inside

- Live SoloJS editor
- Compiled JavaScript panel
- Console / DOM preview iframe
- Download `.js`

## CLI

```bash
dotnet run --project src/SoloJs.Cli -- compile examples/js/counter.solojs
```
