# SoloRUST Studio

Experimental browser GUI for SoloRUST — SoloGem Solo5.

## Run

```bash
dotnet run --project src/SoloRust.Studio
```

Open **http://localhost:5092**

## What’s inside

- SoloRUST editor
- Generated Rust source panel
- Research notes on each compile
- Download `.rs`

## CLI

```bash
dotnet run --project src/SoloRust.Cli -- compile examples/rust/showcase.solorust
dotnet run --project src/SoloRust.Cli -- notes
```
